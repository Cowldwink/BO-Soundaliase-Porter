# BO-Soundaliase-Porter
## Intro
- Set of Powershell scripts to port soundaliases throughout T5 & T6.
## Features
- Mapped out volume groups, duck groups, curves, and etc by best matching names, context or values.
## Usage
- Run `Launch.bat` to launch the script and select the soundaliase you wish to port to the other game.
- The output will be produced at `.\Output\`.
